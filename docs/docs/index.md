# The Minimal Programming Language

Welcome to the Minimal programming language, a language that is both simple and powerful,
enabling the programmer to write expressive code that compiles to fast bytecode.

This website contains its _official_ documentation.

It consists of:

- The Reference Book;
- The Technical Book;
- The Specification Book.

## Which one do I read?

Read:

**The Reference book** if you want to learn how to program in Minimal and how to use its tools,
giving you the necessary skills to write both good and efficient Minimal code.

**The Technical book** if you want to explore _how_ the official compiler and runtime for Minimal were implemented.
You can go here if you want to know how its official compiler implements the language according to its specification.

**The Specification book** if you want to implement a Minimal compiler _yourself_. This is the official specification,
which all compilers (including the official one) must adhere to. Any changes to the language itself will be documented here.
