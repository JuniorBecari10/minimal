## Installation

To use the language we must first install it. <br />
Currently there is no official installation tool, so we need to manually install it.

## Installing on Linux

1. Download the three binaries (`min`, `minc` and `minvm`) or compile them from source.
1. Preferrably put all of them in a single folder. The folder may be wherever you like,
but it is recommended to put it in your home folder (`~`).
1. Add the folder to the `PATH`; do it by `export`ing it to the `PATH` environment variable,
using the `export` command.

## Checking the installation

To check if all programs have been installed, run:

```
$ min version
$ minc version
$ minvm version
```

If their respective version numbers appear, you're all set.
