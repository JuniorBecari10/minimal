## Writing the code

It is time to write your first Minimal program.

> Note: It is recommended to create a separate folder to put all your Minimal files in.

1. Create a new file called `main.mn`. <br />
All Minimal source files and with the `.mn` extension.

Enter this code in it:

_main.mn_
```rust
fn main() {
    println("Hello, world!");
}
```
_Listing 1.1 - A program that prints `Hello, world!` into the terminal screen._

Having saved the file, run these commands into the terminal:
```
$ minc main.mn main.mnb
$ minvm main.mnb
```

The `min` helper command simplifies it to this command:
```
$ min run main.mn
```

This command does automatically the two commands mentioned above. <br />
It is recommended to use it, because it is simpler, reduces more operations
into one single command and is less error-prone.

## Explanation

Let's revise the code.

### `fn main()`

```rust
fn main() {
    
}
```

This is a function definition. Its name is `main`, and it is a special one. <br />
It is special because it is the entry point of your program.

Although this is a simple language, and may be compared to scripting ones, you _can't_ write statements that are not declarations
at the top level. This is why you need a function to write your code using statements.

Because this function is the entry point of the program, it does not need to be called explicitly;
the compiler automatically inserts a call to it.

The function _must not_ take any arguments and not return anything (return type set to `void`; see [types]).

### `println()`

```
println("Hello, world!");
```

The `println` function takes an argument and it can be of any type. <br />
It prints the argument you supply to it to the _standard output_ as a `str`.

All types can be converted to a string (see [type conversion]).

This function is _built-in_, which means it is not written using Minimal bytecode. <br />
Instead, the runtime implementation needs to implement it (in this case, it is implemented in C and so does the function).
