# 2.1 - Variables

Like almost all general-purpose programming languages, Minimal has variables.

Variables in Minimal are immutable by default, which means you can't change its value
after its declaration. This is good because it prevents mutability mistakes and makes the code
easier to reason about.

## Syntax

Variables are declared using the `let` keyword, like the following example:

```rust
let x = 10;
```

Here, we are declaring an immutable variable named `x`, with the value `10`.

Try to do this:

```rust
let x = 10;
x = 11; // ERROR!
```

## Mutability

Minimal has immutable variables by default, in order to prevent bugs, but if we want to, we can make a variable mutable as well.

To do that, just swap `let` by `var`:

```js
var x = 10;
```

This means we can now change the value of the variable.

> Note: if we declare a variable as mutable and not change its value, the compiler will emit an warning. So, if you won't change the value of your variable, declare it using `let`.

Now we can change the value of the variable:

```rust
let x = 10;
x = 11; // OK!
```
